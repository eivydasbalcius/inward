## Working rules
- `docs/KNOWLEDGE.md` is the project knowledge base. Read it before planning; reuse what it lists instead of rebuilding.
- After every feature, fix or decision: update `docs/KNOWLEDGE.md` (map, data model, logic, status) and add a changelog line.
- Plans cover only the current task and reference the knowledge base; never repeat project history.
